# Nightshift

AI-powered SRE agent that detects production errors, diagnoses root cause 
via LLM + git diff correlation, and requests human approval before acting.

**Status:** 
    - Phase 1 — Observer (completed)
    - Phase 2 — Advisor (in progress)
    - Phase 3 — Actor (not started)

## Stack
- Backend: FastAPI + LangGraph
- Frontend: Angular
- Mobile: Android (Kotlin)

See [docs/](./docs) for full architecture and roadmap.
